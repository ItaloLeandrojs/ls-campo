# LS Campo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sistema de demonstração LS Campo (planejamento de equipes de manutenção predial, empresa fictícia Arremate) com página de apresentação animada, publicado no GitHub Pages.

**Architecture:** Astro gera a apresentação estática (`/`) e uma página `/app/` que monta um app React único (`client:only`) com HashRouter. Domínio (regras, indicadores, semente) é JS puro testado com Vitest; estado em Zustand persistido no localStorage; fotos no IndexedDB. Movimento segue taste-skill + ls-motion.

**Tech Stack:** Astro 7, @astrojs/react, React 19, react-router 7 (HashRouter), zustand, @dnd-kit/core, idb-keyval, motion, gsap, @phosphor-icons/react, three + @react-three/fiber + @react-three/drei + @react-three/rapier + meshline (só crachá, lazy), Vitest, Playwright (Edge).

**Spec:** `docs/superpowers/specs/2026-10-07-ls-campo-design.md`

## Global Constraints

- Base do site: `/ls-campo/` (GitHub Pages `https://italoleandrojs.github.io/ls-campo/`). Caminhos sempre com `import.meta.env.BASE_URL`.
- Git Bash: builds com base usam `MSYS_NO_PATHCONV=1`.
- `noindex` em todas as páginas até o OK do Italo (constante `INDEXAR = false` em `src/config.js`).
- Português; zero travessão (— ou –) em texto visível; nenhum termo da lista `../ls-campo-termos-proibidos.txt` no código ou no build.
- Contexto privado nunca entra no repositório (repo público).
- App: tema claro padrão, botão escuro; apresentação escura. Acento azul: `#2F62D6` (claro) / `#5B8CF0` (escuro). Roboto Flex + Roboto Mono (números tabulares).
- Cores de etapa sempre com o nome escrito: Novo cinza, Agendado azul, Em execução âmbar, Concluído verde, Reagendar vermelho.
- Tudo com versão para "reduzir movimento" e alvo de toque ≥ 44 px no app da equipe.
- Downloads de vídeo/fotos de banco só com aprovação do Italo; até lá, componentes funcionam com material provisório próprio (prints do app) e a lista de candidatos fica em `docs/candidatos-midia.md`.

## Review Focus

- localStorage cheio ou bloqueado (navegação privada): o app deve funcionar em memória e avisar "Não foi possível salvar neste navegador", sem quebrar. Teste em `loja.test.js`.
- Data de hoje num domingo: a agenda abre na semana seguinte com aviso, e a semente não cria nada no domingo. Teste em `semente.test.js` e `datas.test.js`.
- Dados salvos de versão anterior (chave antiga ou formato diferente): carregar a semente nova em vez de quebrar. Teste em `loja.test.js` (migração).
- Foto enorme (12 MB, 4000 px) ou arquivo que não é imagem: reduzir para 1280 px ou recusar com mensagem clara. Teste no E2E com arquivo de teste.
- Fuso e virada de dia (abrir às 23:59 e usar depois da meia-noite): "hoje" recalculado ao focar a janela; datas guardadas como `AAAA-MM-DD` local, nunca ISO UTC. Teste em `datas.test.js`.
